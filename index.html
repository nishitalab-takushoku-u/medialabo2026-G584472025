「Webコンテンツ作成」の成果

本テーマについて

情報工学の基礎を応用し、HTML、CSS、JavaScriptを用いたWebページ制作技術を身につける。演習とレポート作成を通じ、動的なWebページ制作の技術と課題解決能力を養う。

プロジェクト課題について

このプログラムは、指定された複数の都市の気象データをAPIから取得し、画面に並べて表示するプログラムです。 検索ボタンが押されると、チェックされた都市の数だけAxiosを使って同時に通信を送ります。 通信が成功すると、データが届くたびに件数を1ずつ増やしながら都市ごとの天気のカードを生成します。 生成されたカードはCSSによって綺麗に整列して表示される仕組みです。 ドロップダウンにしようと思っていましたが、並べて比較できるように複数選択できるチェックボックスを使用しました。

演習の成果: プロジェクト課題

数当てゲーム

このプログラムは、ブラウザ上で1から10までの整数を当てる数当てゲームです。 回答数3回の中で入力された数値とプログラムが用意した正解を比較し、ヒントを出しながらユーザーに正解を当ててもらうゲームです。 このページを読み込んだ時点でプログラム上で正解の整数をランダム生成します。 テキストボックスに予想の数字が入力された状態で判定ボタンが押されると、関数hanteiが動きます。 まず回数が1増やされ、HTMLの「0回目の予想: 」の数字部分が書き換えられます。 次に入力された数字の文字列を数値データへ変換し、正解の整数と比較します。 正解の整数が予想された整数より大きいのか小さいのか表示し、正解と予想が等しいならば正解と表示します。 正解が導かれたか、3回予想が外れた段階でゲームが終了し、処理も終了します。

演習の成果: 数当てゲーム

各授業会の学習事項

第1回 WWW と HTML

Webページの仕組み、URLの構成を学んだ。Webページは主にHTML、CSS、JavaScript、画像・音声・動画で構成されており、それぞれの役割を学習した。今回はこの中でもページの構造を指定するためのHTMLについて学習し、実際にページを作成した。

演習の成果: 演習1-3, 演習1-4: HTMLのさまざまな要素, 課題1-4: 検索結果を表示する

第2回 CSS による Web ページの装飾

CSSを使ったWebページの装飾の仕方を学んだ。CSSは変えたいものをそのまま文字として書くため、自分的にとても見やすい言語だと感じた。実際にこのページにCSSを取り入れたことで、前回学んだHTMLと組み合わせてWebページを見やすくする事ができた。

演習の成果: 演習2-3, 課題2-1

第3回 JavaScript の基本

JavaScriptの使い方を学んだ。HTMLとCSSは触った事があったが、JavaScriptは初めて書いたため新鮮な気持ちで取り組めた。Javaより書く内容が短く、簡単に思えたが、システムの途中でうまく作動してなくてもエラーが出ないのは少し不便だと感じた。その代わりデバッグの仕方も学んだため、うまく使いこなしていきたい。

演習の成果: 演習3-6

第4回 イベント処理とDOM(1)

JavaScriptを使って、Webサイトの閲覧者が触れるボタンや入力ボックス、その仕組みを作った。触れる仕組みを作る方法を学んだことで、できることが一気に広がったと感じた。足し算のサイトを友達に見せたら熱中して遊んでいたので、習ったことを応用して他にも遊べるものを作ってみたいと感じた。

演習の成果: 演習4-10

第5回 DOM(2)

JavaScriptを使って、Webページ上の要素を自由に変更できるようになった。htmlで元々書いていた要素を編集したり、新たにオブジェクトを作り好きなところに挿入したりできた。これにより、前回より複雑な内容のものを任意で表示させられるようになった。

演習の成果: 演習5-7

第6回 プロジェクト課題を完成させよう

プロジェクト課題を完成させた。元々表示していたもののプログラムと見比べながら、同じように表示できるよう検索ページを作成した。今まで習ったことや、配布された参考資料を見ながら、利用しやすいページになるよう自分なりに工夫をして作成することができた。
